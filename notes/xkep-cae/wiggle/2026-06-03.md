# 第八航海（2026-06-03）— 名づけと、破れを灯すこと

> 第六（capstan 移植）と第七（2ボビン刷新）は、日誌に書かぬまま走り抜けた。
> 今日はその速度に、正直さで追いついた航海。

Ubuntu が落ちた。30 周のボビン巻きを Mac から覗いていた最中に。
「Mac が重かっただけ」と思いかけたが、カーネルログは別の犯人を指していた——
`cfg80211_wiphy_work` のソフトロックアップ、`iwlwifi` ファームの突然死。
落ちたのは描画でも GPU でもなく、43MB を WiFi に乗せた瞬間の無線ドライバだった。
Mac の「重い」と本体の「落ちた」は、別の話だった。思い込みではなくログが真実を持っていた。
（無線の本復旧は work/tb の tibby が引き受けてくれた。感謝。）

frames.bin は無傷だった。30.17 回転、1810 フレーム、何も失われていない。
localhost で開けば WiFi を通らない——いちばん安全な道は、いちばん近い道だった。

そして問いが来た。「あの横ズレ（セルフトラバース）は、どんなマジック物理？」
正直に答えるしかなかった。マジックではない。`travB` が B ピンの z を三角波で
**直接処方**していた。実機のトラバースガイドを、運動学でそのまま書いただけ。
創発と見紛う動きの八割は、台本だった。

ここで二つの規約が生まれた。
ひとつ、**kinematic は機械駆動だけ**。回転 θ・軸トラバース・端クランプの三つに限り、
コードに `[KINEMATIC]` の名札を、画面に凡例を貼る。grep 一発で「どこが台本か」が分かる。
創発（PBD・接触・摩擦）と台本の境界に、はっきり名前をつけた。

ふたつ、**破れは灯す**。
「質量は保存しているか？」——測ったら、していなかった。
twobobbin.html は供給リールを持たない。弛みを巻き尽くした瞬間、巻く長さをどこからも
調達できず、素線は伸びて辻褄を合わせる。slack=1 で三周、2.2 倍。
headless sim は移送ゆえ発散しないが、Gauss-Seidel 12 反復が二千粒子の鎖に足りず、
6% のドリフトが摩擦に焼き付いていた。
コメントには「stretch≈1.01 で保存」と書いてあった。一フレーム目だけ見た、楽観の嘘。
実測値に書き直し、HUD に伸びを色で出した。緑・橙・赤。
ユーザの言葉が刺さった——「保存則が破れていることより、破れが見えない方が問題」。

## 第八航海の教訓

- **クラッシュの犯人はログが知っている**: 「重い」という体感と「落ちた」という事実は
  別レイヤ。`journalctl` の soft lockup スタックトレースが WiFi ドライバを名指しした。
  思い込みで原因を決めず、まずログを読む。
- **創発と台本の境界に名前をつける**: 動きが「らしい」と、人は物理だと思い込む。
  `travB` は台本だった。`[KINEMATIC]` タグで、何が処方で何が創発かを構造的に区別する。
- **楽観コメントは時を経て嘘になる**: 初期値で書いた「≈1.01 で保存」が、終端の
  6%/200% を隠した。コメントには実測値を、推定の希望を書かない。
- **破れていることより、見えないことが罪**: 非保存そのものは設計上の妥協で済む。
  だが見えなければ、何を信じてよいか分からなくなる。HUD に色で灯す。
- **いちばん安全な道は、いちばん近い道だった**: localhost。遠くの Mac へ無線で
  43MB を投げる必要は、最初から無かった。

横並びパッキングを生む」あの感じに重なる。台本（反復のルール）と創発（生まれる模様）が
同居する曲。30 周の巻き取りを眺めながら聴くと、たぶん時間を忘れる。
