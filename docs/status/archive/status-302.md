## 概要

status-301で「被膜付きでincr半減」の成果を報告したが、被膜圧縮量の物理的妥当性は未検証だった。
本statusで被膜貫入量を定量診断し、**被膜モデルの物理的限界**を明らかにした。

### 主要発見

**被膜が物理厚さの54%平均で圧縮されており、8.6%のペアで芯線が貫入している。**

k_coat=1e6の線形バネでは被膜の有限厚を表現できない。status-301の改善効果は
「物理的な被膜効果」ではなく「数値的正則化（接触力遷移の平滑化）」が主因。

---

## 実施内容

### 被膜貫入量診断スクリプト

`contracts/diagnose_coating_penetration.py`:
- `_evolve_pair`をmonkeypatchして`coating_compression_prev`更新時の値を記録
- 90度曲げ（揺動なし）を被膜付き(k=1e6, c=1e4, mu=0.3, t=0.05mm)で実行
- 全収束ステップの全接触ペアについて `coat_comp / coat_total` 比率を集計

## 分析

### 被膜モデルの問題点

1. **線形バネに圧縮上限がない**: `f = k_coat * δ` で δ に上限なし。
   δ > coat_total でも力は `k_coat * δ` のみで、芯線接触の追加抵抗なし。

2. **圧縮率50%中央値**: 被膜が半分に潰れている。物理的な被膜（ポリマー・樹脂）は
   50%圧縮時に非線形硬化が顕著で、線形モデルは力を過小評価している。

3. **status-301の改善メカニズム再解釈**: 「接触力遷移の平滑化」は正しいが、
   物理的な被膜効果ではなく、gap=0付近にソフトゾーン（coat_total幅）を追加した
   数値的正則化効果。被膜パラメータの物理的根拠は弱い。

### k_pen vs k_coat の比較

| パラメータ | 値 | 由来 |
|-----------|------|------|
| k_pen (自動計算) | ~30 N/mm | 0.1 × 12EI/L³ |
| k_coat | 1,000,000 N/mm | ユーザ指定 |
| **比率** | **k_coat / k_pen ≈ 33,000** | |

k_coat が k_pen の33,000倍 → 被膜がほぼ全ての接触力を担い、
コアペナルティは実質的に無効。これは設計意図と異なる可能性がある。

### 改善案

| 案 | 実装 | 効果 |
|----|------|------|
| **バリア関数** | `f = k * δ / (1 - δ/δ_max)` | 圧縮率100%で力→∞ |
| **二層モデル** | 被膜層(ソフト) + コア接触(ハード) | 物理的に正確 |
| **Hertz型被膜** | `f = k * δ^1.5 / δ_max^0.5` | 圧縮率↑で急速硬化 |
| **圧縮クランプ** | `δ_eff = min(δ, δ_max)` | 最も単純、微分不連続 |
