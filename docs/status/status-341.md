## 仮説 C 反証の考察

### なぜ倍化で悪化したか？

**仮説 C-反証-α（有力）**: 増分サイズ縮小により 1 増分あたりの接触ペア活性化数が減ることで
**「初回活性化 → 摺動確立」の動的平衡が崩れた**。具体的には:

- n_incr=20 ではギャップ閾値を横切るペアが incr あたり 2-3 ペア
- n_incr=40 では 1 ペア以下になり、**単発ペアが stick/slip チャタリングを起こしやすい**
- 凍結モード（status-284）が発動する前の「最初の 1-2 iter での活性集合ジャンプ」が
  収束性を決めているため、増分粗さは直接的原因ではない

**仮説 C-反証-β（補助）**: 増分サイズ縮小で**絶対変位スケールが小さくなる**ため、
K_c FD 相対誤差（status-291, 295 で 1.8% まで追い込んだ）の**「小さい数値に対する
相対誤差」** が実効的に増幅する。n_incr=40 では x 成分誤差が 97% に達しており、
これは status-339 の z 成分 65% より悪い。

### 残る仮説の優先順位更新

| 仮説 | status-339 優先順位 | 本試行後の評価 |
|------|------------------|---------------|
| A: StJacobian z 成分カップリング不整合 | 4（最後の手段） | **1（最有力）** — z=70% 残存かつ x=71% も追加、成分選択性ではなく **広範な K_c 不整合** の可能性 |
| B: gap_cull_threshold が接触ペア見落とし | 3 | 2（変更なし） — 簡単に掃引可 |
| C: 曲率プロファイル過粗さ（n_incr） | 2 | **反証済み**（本試行） |
| D: 凍結パラメータ最適化 | 4 | 3 — 凍結が効いている証拠は見当たるが根治策ではない |

### 観察された physical な事実（frac=0.199 時点）

- max \|u\| = 14.91（mm スケール） — 弾性的に変形は進んでいる
- active pairs = 11、**全て内層-外層（1,2）ペア** — 物理的には妥当（外層は内層より
  大きく振れるため、接触先として内層を選ぶ）
- sliding = 571（stick＜slip） — 摩擦が飽和しており、κ_cr は既に越えている

**重要**: 層分類器が **（1, 2）カテゴリ単独** を正しく抽出したことで、status-340 の
「完走を待たずに層分類実行可能」という設計判断が**実運用で裏付けられた**。
