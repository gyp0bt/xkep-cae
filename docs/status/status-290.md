## 概要

status-289で特定された「comp=2(z方向)に接線剛性不整合が集中」の知見を深堀り。FD接線診断にcomp別不整合分布と接触/構造DOF分離を追加し、90度曲げで詳細な分解結果を取得。

### 最重要発見

1. **z方向が不整合の84-93%を占める**（一貫して支配的）
2. **x方向も35-57%と有意に大きい**（y,θ方向はほぼ正確）
3. **不整合は構造DOF（1.0e-2）> 接触DOF（2e-3〜1e-2）** — 接触ペアの直接DOFだけでなく周辺にも波及
4. **dm補正有効化を試行したが改善せず** — 問題はdm以外の幾何項にある可能性

## 実装内容

### FD接線診断の強化

`TangentFDDiagnosticProcess` に以下を追加:

| 項目 | 内容 |
|------|------|
| comp別不整合分布 | x,y,z,θx,θy,θzの各成分ごとの不整合ノルムと全体に占める割合 |
| 接触/構造DOF分離 | active_contact_dofs vs 非接触DOFの不整合ノルムを分離出力 |

**出力例**:
```
  comp別不整合: [x:3.78e-03(35%), y:5.60e-04(5%), z:9.95e-03(93%), θx:1.34e-04(1%), θy:1.91e-04(2%), θz:1.14e-05(0%)]
  接触DOF不整合: 2.14e-03 (36 DOFs), 構造DOF不整合: 1.04e-02 (678 DOFs)
```

### dm補正有効化の試行と撤回

tangent()とevaluate()の`_node_counts`を計算してdm補正（∂m/∂u）を有効化したが:
- K_c_adjのFDテスト（TestKcAdjFD）で12.5%の不整合が発生
- 90度曲げではdir_ratio=1.000のまま改善なし
- **リバート済み**（dm補正以外の不整合が支配的）

## 根本原因の考察

### なぜz方向とx方向に集中するか

7本撚線のヘリカル構造では:
- 接触は主にx-y平面で発生（素線間の径方向接触）
- z方向は素線軸方向（ピッチ方向）
- x方向とz方向の不整合が大きいのは、**ヘリカル構造のピッチ角によるx-z結合**が接線剛性でモデル化されていないことを示唆

### dm補正が効かなかった理由

- dm補正は形状関数の端部重み補正であり、z方向のカップリングを追加するものではない
- FD不整合の上位DOFを見ると、接触ペアの直接ノードだけでなく**遠方ノード**にも不整合がある
- これはK_c/K_stの局所的な不正確さではなく、**接触ジオメトリ更新（gap/normal/s,t）がuに対して非線形に変化する**効果がK_Tに含まれていない可能性

### 構造DOFの不整合が大きい理由

FD診断でR(u+eps*du)を計算する際、接触ジオメトリ更新が全ペアに対して実行される。摂動duの効果が:
1. beam内部力（K_struct）に影響 — 正しく計算
2. 接触力f_cに影響（gap/normal変化） — K_c+K_stでカバー
3. **接触力変化がbeam残差に反映** — K_c+K_stの不正確さが構造DOFに波及

つまり「構造DOFの不整合」は、構造要素K_struct自体の問題ではなく、**K_cの不正確さが構造DOFの残差に伝播した結果**。
