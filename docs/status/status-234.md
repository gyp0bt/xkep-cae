## 設計知見

### SDI 排除の効果メカニズム

1. **全候補ペア Huber 評価**: 離散的な ACTIVE/INACTIVE 切り替えを排除
   → 接触力の連続的変化 → dt 回復ロジックが正常に機能
2. **力ベース dt 制御**: 連続量 `|Δ‖f_c‖|/‖f_c‖` で dt 調整
   → 面積増加やスライドでは dt 縮小が発生しない
3. **g_off ワイド化**: 0.1mm（ワイヤ半径の 1.2%）
   → 微小ギャップ開きでの状態フリップを防止

### 残課題

- 中盤後〜終盤（frac 0.5–0.9）で dt が大幅縮小する傾向は残存
- NR 残差収束が遅い（25反復で tol_force=1e-6 に届かず disp 収束で抜ける）
- 接線剛性の精度改善（特に摩擦接線）が更なる dt 改善のカギ
